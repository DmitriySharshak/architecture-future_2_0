|Технология/Методология|Кольцо|Поддерживаемые бизнес-сценарии|
|--|--|--|
|ClickHouse|Применять|Быстрая отчётность по терабайтам данных; финтех-витрины|
|Apache Kafka + Debezium CDC|Применять|Реалтайм-интеграция между доменами; события записи клиник|
|Data Mesh|Применять|Независимое развитие финтех, ИИ, клиник; подключение новых партнёров|
|RBAC + Row-Level Security|Применять|Медицинские данные не попадают в аналитику; комплаенс|
|Go (для высоконагруженных сервисов)|Пробовать|Портал самообслуживания, API-шлюз для партнёров|
|Apache Superset|Пробовать|Self-service BI поверх витрин (легче кастомизации, чем Power BI)|
|Kubernetes (Managed, например, Yandex Managed K8s)|Пробовать|Масштабирование доменов, отказоустойчивость|
|Open Policy Agent (OPA)|Оценивать|Тонкая политика доступа к разным типам данных (мед/фин)|
|SQL Server 2008|Отказаться|Не масштабируется, небезопасен, тормозит отчётность|
|PowerBuilder|Отказаться|Мёртвая технология, высокие затраты на поддержку|
|Apache Camel (ESB)|Отказаться|Заменяется на Kafka; узкое место потоков|
|Power BI с прямым подключением к DWH|Отказаться|Переводим только на витрины через Superset|
